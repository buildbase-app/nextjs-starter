## Sites, and the specific thing each does well

- **linear.app**: real product UI in the hero; sections captioned like
  technical figures; dated changelog entries on the homepage.
- **stripe.com**: product UI as cards (a usage meter, risk scores); exact
  numbers instead of adjectives.
- **vercel.com**: visible grid lines as ornament; Geist sans + mono; a CLI
  line as a call to action.
- **cursor.com**: interactive mockups on painted backgrounds, not gradients.
- **raycast.com**: real hotkeys printed on the page; install line.
- **planetscale.com**: text-first, almost brutalist, ASCII diagrams. The
  anti-slop extreme.
- **clerk.com**: an agent prompt and a one-line `npx` in the hero; renders
  its real `<SignIn/>`.
- **supabase.com**: real editors on the page; Launch Week tickets people
  share.
- **railway.com**: the product's own canvas as the hero.
- **posthog.com**: a voice and illustrations with personality; a public
  handbook.
- **warp.dev**: a terminal that plays real commands.
- **tldraw.com**: the homepage is the product.
- **oxide.computer**: mono labels, technical drawings, public RFDs.
- **mercury.com**, **diabrowser.com**: warm editorial serif, calm colour.
- **family.co**: spring physics; transitions you can interrupt.
- **apple.com** product pages: one idea and one number per screen.
- **igloo.inc** (Awwwards Site of the Year 2024), **lusion.co**,
  **activetheory.net**: the WebGL ceiling. Study, do not imitate.

A 2025 study of 100+ dev-tool landing pages (Evil Martians) found most use one
template: centred hero, product visual, logo strip, feature grid, FAQ.
Breaking it on purpose in one or two places is what people remember.

## Ideas not built yet (for this demo)

- **The tour as a constellation**: 122 tasks as points grouped by module; a
  finished task lights up; a shareable image of your progress.
- **Agent lane**: one side a person clicks through a task, the other an
  agent does it over MCP with the tool calls visible.
- **Animated webhook flow**: upgrade a plan, watch a signed event travel,
  retry once, land as a row.
- **Live changelog strip**: the latest four SDK releases, dated, at build.
- **Deep-linkable demo state**: `?step=credits` opens the hero panel there.
