Esta aplicación de demostración es un proyecto Next.js 16 que usa el SDK de BuildBase para conectar auth, facturación, notificaciones y más — sin escribir la infraestructura.

No hay lógica de auth personalizada, código de procesamiento de pagos ni infraestructura de entrega de notificaciones en este repositorio. Todo eso lo maneja la plataforma backend de BuildBase. Lo que ves aquí es el frontend — una aplicación Next.js real con llamadas SDK reales en la que puedes iniciar sesión e interactuar.

Inicia sesión con el botón del encabezado, luego explora el panel de control para ver cada capacidad funcionando en vivo. El código fuente de cada función está en la página o ruta de API correspondiente en el repositorio.
