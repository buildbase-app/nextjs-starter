Cette application de démonstration est un projet Next.js 16 qui utilise le SDK BuildBase pour connecter l'auth, la facturation, les notifications et plus encore — sans écrire l'infrastructure.

Il n'y a pas de logique d'auth personnalisée, pas de code de traitement des paiements et pas d'infrastructure de livraison de notifications dans ce dépôt. Tout cela est géré par la plateforme backend BuildBase. Ce que vous voyez ici est le frontend — une vraie application Next.js avec de vraies appels SDK dans laquelle vous pouvez vous connecter et interagir.

Connectez-vous avec le bouton dans l'en-tête, puis explorez le tableau de bord pour voir chaque fonctionnalité fonctionner en direct. Le code source de chaque fonctionnalité se trouve dans la page ou la route API correspondante dans le dépôt.
